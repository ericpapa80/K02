4부

The Play하이브리드 모델 제안

The Inevitable Conclusion

왜 하이브리드 모델인가?

성공은 '제로섬 게임'이 아닌, '지혜로운 융합'에 달려있음

'Universe(팬덤)' 모델 Only

→ 지역사회 소외, 공공성 상실

'Commons(커뮤니티)' 모델 Only

→ 브랜드 임팩트 및 팬덤 강화 기회 상실

∴ 각 모델의 핵심 장점을 결합한 하이브리드 모델이 최적의 선택

Core Concept

Community-driven Fan Universe

팬덤을 위한 핵심 브랜드 경험(Fan Universe)은 유지하되, 공간의 기반은 지역 커뮤니티(Community)에 두어 성수동의 '일상'과 크래프톤의 '이벤트'가 자연스럽게 조화되는 모델
